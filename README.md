# ⛏ クラフトワールド

Three.js製のMinecraft風ボクセルサンドボックスゲーム。ブラウザだけで動きます。

**▶ 遊ぶ：** https://fuji40254025.github.io/minecraft-clone/

## 特徴

- パーリンノイズ風の無限地形生成（平原・丘・山・海・砂浜・木）
- ブロックの破壊・設置（9種類：草・土・石・砂・原木・木材・葉・ガラス・レンガ）
- 一人称視点・物理演算（重力・ジャンプ・水泳・飛行モード）
- 昼夜サイクル（約8分周期）
- **サバイバル**：初期アイテムなし。ブロックを壊して素材を集める（草→土、石→丸石など本家準拠ドロップ）
- **インベントリ＆クラフト**：持ち物27枠＋2×2クラフトを最初から所持（Eキー / 🎒ボタン）
- **作業台**：木材4でクラフト→設置→右クリックで3×3クラフトが開く
- **武器**：本家レシピで木の剣・石の剣を作成（原木→木材→棒→剣）。素手より大ダメージ
- モブ：ブタ🐷・ヒツジ🐑が放浪、夜はゾンビ🧟・スケルトン🏹（弓矢）・クリーパー💥（爆発でブロック破壊）が出現
- 戦闘・体力システム：クリック/⛏でモブを攻撃（ノックバック付き）、敵にやられるとハート減少、時間で自然回復、0になるとスポーン地点へ

## クラフトレシピ

| 完成品 | 材料（配置） | 必要な台 |
|---|---|---|
| 木材×4 | 原木1 | 2×2でOK |
| 棒×4 | 木材を縦に2 | 2×2でOK |
| 作業台 | 木材を2×2 | 2×2でOK |
| 木の剣 | 木材2＋棒を縦1列 | 作業台(3×3) |
| 石の剣 | 丸石2＋棒を縦1列 | 作業台(3×3) |
- 建築はブラウザのlocalStorageに自動保存
- テクスチャ・効果音もすべてコードで自動生成（画像・音声ファイル不要）

## 操作方法

### PC（キーボード・マウス）

| 操作 | キー |
|---|---|
| 移動 | WASD |
| ジャンプ | Space |
| スニーク（低速） | Shift |
| 飛行モード切替 | F（飛行中 Space↑ / Shift↓） |
| ブロック破壊 | 左クリック（長押しで連続） |
| ブロック設置 | 右クリック |
| スポイト | 中クリック |
| ブロック選択 | 1〜9キー / マウスホイール |
| メニュー | Esc |

### スマホ・タブレット（タッチ）

| 操作 | 方法 |
|---|---|
| 移動 | 左下のバーチャルパッド |
| 視点 | 画面をドラッグ |
| ブロック破壊 | ⛏ ボタン（長押しで連続） |
| ブロック設置 | 🧱 ボタン |
| ジャンプ / 上昇 | ⬆ ボタン |
| 飛行モード切替 | ✈ ボタン（飛行中は ⬇ で下降） |
| ブロック選択 | ホットバーを直接タップ |
| メニュー | ⏸ ボタン |

## ローカルで動かす

`index.html` をブラウザで開くだけ（Three.jsのCDN読み込みにネット接続が必要）。

## 構成

- `index.html` — UI・スタイル
- `game.js` — ゲームエンジン本体（地形生成・メッシュ構築・物理・入力・保存）
